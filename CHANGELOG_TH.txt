V5.4 Compact UI Edition
----------------------
- ปรับขนาดหน้าต่างเริ่มต้นเป็น 880 × 680 และลดขนาดขั้นต่ำ เพื่อใช้พื้นที่หน้าจอน้อยลง
- จัดหน้า Control ใหม่ให้สถานะเป็น 2 คอลัมน์ แยกค่าตั้งหลัก และทำปุ่มเริ่ม/หยุดให้เด่นชัด
- เพิ่มแถบเลื่อนและรองรับเมาส์วีลในทุกแท็บ เพื่อให้ใช้งานได้แม้หน้าต่างมีขนาดเล็ก
- ปรับระยะห่าง ฟอนต์ ปุ่ม ช่องกรอก และแท็บให้กะทัดรัดขึ้น พร้อมแสดง V5.4 ใน title bar และหัวโปรแกรม
- อัปเดตชื่อเวอร์ชันในคู่มือ ไฟล์ VERSION และ Log โดยคง Config Schema V5 เพื่อใช้ไฟล์ตั้งค่าเดิมต่อได้

V5.2
- เปลี่ยนมินิเกมเป็นการควบคุมแบบ Fisch: กดค้างดันบล็อกควบคุมไปขวา / ปล่อยให้ไหลกลับซ้าย
- ตรวจจับบล็อกควบคุมสีขาว/เทาอ่อนและตัวบอกปลาสีม่วง/เทาอมฟ้า แยกจากกัน
- เพิ่ม deadband และ lookahead สำหรับการติดตามตำแหน่งปลา
- รองรับ Progress ทั้งสีส้มอมชมพูและสีขาว
- ปรับการยืนยันจบมินิเกมเมื่อ Progress/ตัวบอกปลาหาย โดยใช้ค่า Progress สูงสุดที่เคยอ่านได้
- กด F6 ครั้งเดียวแล้ววนตกปลาใหม่อัตโนมัติจนกด F7 หรือปิดโปรแกรม; ไม่มี checkbox ปิดการวนซ้ำ
- ปรับสถานะและ Debug Preview ให้แสดงแถบควบคุม/ตำแหน่งปลา
- ปรับคู่มือและชื่อเวอร์ชันเป็น V5.2

V5.1
- ปรับ Charge Detector ให้ค้นหาเสาสีขาวใต้ส่วนสีเขียว/เหลืองเขียว แม้กรอบ B มีพื้นที่รอบแถบ
- ปรับ Handle Detector ให้รองรับแท่งม่วงเข้ม ขอบม่วง และแท่งม่วงอ่อนที่ซ้อนอยู่บนโซนขาว
- ปรับ Progress Detector ให้รองรับสีส้มอมชมพูและสีขาวจากภาพจริง
- เมื่อ UI Click & Hold หายไปหลัง Progress ผ่าน 78% และหายต่อเนื่อง 0.55 วินาที ให้ยืนยันว่ามินิเกมจบ
- เปิดการตกปลาใหม่อัตโนมัติเป็นค่าเริ่มต้น และวนต่อเนื่องจนกด F7 หรือปิดโปรแกรม
- เปลี่ยนเวลาทำงานรวมเริ่มต้นเป็น 0 (ไม่จำกัด)

V5.0
- แยก Config, Win32 window/capture, vision, mouse input และ engine เป็นโมดูล
- เปลี่ยนการเก็บพิกัดเป็น normalized client coordinates
- เพิ่มการตรวจจับหน้าต่าง Roblox อัตโนมัติและตรวจ foreground ก่อนส่ง input
- เพิ่มการยืนยัน UI หลายเฟรมก่อนเริ่มมินิเกม
- เพิ่ม Debug Snapshot PNG + JSON และ logging แบบหมุนไฟล์
- ปิด timed charge fallback เป็นค่าเริ่มต้นเพื่อไม่ปล่อยเบ็ดโดยเดาสุ่ม


V5.3 Recovery
--------------
- เพิ่ม Recovery Loop เมื่ออ่าน Charge ไม่พบ, มินิเกม/ตัวบอกปลาหาย หรือรอ UI เกินเวลา
- ปล่อยเมาส์ก่อนทุกครั้งที่พักและลองใหม่ พร้อม exponential back-off (2.5/5/10/15s โดยค่าเริ่มต้น)
- หลังเกิดปัญหา จะสแกน UI มินิเกมเดิมก่อน เพื่อเลี่ยงการเหวี่ยงซ้ำโดยไม่จำเป็น
- เพิ่ม Focus Recovery: พักรอให้ Roblox กลับมาอยู่หน้าสุด/ถูก restore แล้วทำงานต่อโดยไม่แย่ง focus
- F7 และการปิดหน้าต่างยังคงหยุดถาวร ไม่ถูก Recovery เริ่มใหม่
- ข้อผิดพลาด config และปิดหน้าต่างเกมยังคงหยุดเพื่อให้ผู้ใช้แก้ไข
