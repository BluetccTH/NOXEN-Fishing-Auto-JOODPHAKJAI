[ NOXEN ] - FISHING AUTO JOODPHAKJAI V5.3 RECOVERY — WINDOWS 10/11
===================================

V5.3 Recovery ใช้แนวควบคุมมินิเกมแบบ Fisch: กดเมาส์ซ้ายค้างเพื่อเลื่อนบล็อกควบคุมสีขาวไปทางขวา และปล่อยเมาส์ให้บล็อกไหลกลับซ้าย จากนั้นติดตามตำแหน่งตัวบอกปลาเพื่อพยายามให้ปลาอยู่ในบล็อกควบคุม

ฟังก์ชันหลัก
------------
1. ตรวจจับหน้าต่าง Roblox อัตโนมัติ ไม่ต้องกรอกชื่อหน้าต่าง
2. Calibration พื้นที่ A/B/C/D และบันทึกพิกัดแบบสัดส่วนของหน้าต่าง Roblox
3. อ่านแถบชาร์จแนวตั้งจากส่วนสีเขียว/เหลืองด้านบนและส่วนเติมสีขาวด้านล่าง
4. กดเมาส์ค้างชาร์จ แล้วปล่อยเบ็ดเมื่อถึงเปอร์เซ็นต์ที่ตั้งไว้
5. ตรวจจับบล็อกควบคุมสีเทาอ่อน/ขาว และตัวบอกปลาโทนม่วง/เทาอมฟ้า
6. ควบคุมมินิเกมแบบ Fisch ด้วยการกดค้าง/ปล่อย ไม่ได้ลากเคอร์เซอร์ไปมาระหว่างเล่น
7. อ่าน Progress ได้ทั้งสีส้มอมชมพูและสีขาว
8. เมื่อ Progress ถึงเกณฑ์และ UI มินิเกมหายไป จะยืนยันว่ารอบจบแล้ว แม้แท่งปลา/รางจะหายคนละเฟรม
9. กด F6 เพียงครั้งเดียวเพื่อเริ่มวนตกปลาอัตโนมัติ จนกด F7 หรือปิดโปรแกรม
10. Recovery Loop: เมื่อการตรวจจับขาดช่วงจะปล่อยเมาส์ พัก ตรวจสถานะมินิเกมเดิม แล้วลองใหม่เอง
11. Focus Recovery: เมื่อ Roblox ถูกย่อ/เสียโฟกัส จะปล่อยเมาส์และรอจนกลับมาอยู่หน้าสุด
12. Debug Snapshot PNG + JSON, Log, ทดสอบการอ่านภาพ, สำรอง/นำเข้าการตั้งค่า

ติดตั้ง
------
- Windows 10/11
- Python 3.10 หรือใหม่กว่า
- แตก ZIP แล้วเปิด Run.bat
- Run.bat สร้าง .venv ติดตั้ง requirements.txt แล้วเปิดโปรแกรม

ตั้งค่าครั้งแรก
---------------
1. เปิด Roblox และให้หน้าต่างเกมแสดงอยู่บนหน้าจอ
2. ไปแท็บ “ตั้งค่าพื้นที่”
3. A: เลือกจุดบนผิวน้ำที่ต้องการคลิกชาร์จ/เหวี่ยงเบ็ด
4. B: ครอบแถบ Charge แนวตั้งทั้งแท่ง ให้เห็นสีเขียว/เหลืองด้านบนและส่วนสีขาวด้านล่าง
5. C: เมื่อมินิเกมปรากฏ ให้ครอบรางแนวนอนทั้งหมด รวมบล็อกควบคุมสีขาวและแท่งบอกปลาสีม่วง/เทา
6. D: ครอบแถบ Progress ด้านล่างทั้งหมด โดยรวมทั้งส่วนเติมและรางสีเข้ม
7. กด “ทดสอบการอ่านแถบ” ขณะ UI ที่เกี่ยวข้องแสดงอยู่ ตรวจค่า Charge, แถบควบคุม, ตำแหน่งปลา และ Progress
8. ทดลองชาร์จดูว่า Charge เพิ่มขึ้นตามจริงก่อนเปิดใช้งานต่อเนื่อง
9. กด F6 หนึ่งครั้งเพื่อเริ่ม; V5.3 จะเริ่มรอบใหม่และกู้คืนจากข้อผิดพลาดเองหลังจบมินิเกม

กลไกควบคุม Fisch-style
----------------------
- กดเมาส์ซ้ายค้าง: บล็อกควบคุมสีขาวเคลื่อนไปทางขวา
- ปล่อยเมาส์: บล็อกควบคุมไหลกลับไปทางซ้าย
- โปรแกรมเปรียบเทียบตำแหน่งปลาและตำแหน่งบล็อก แล้วสลับกด/ปล่อย
- ค่า deadband เป็นระยะเผื่อป้องกันการสลับ input ถี่เกินไป
- ค่า lookahead ใช้คาดการณ์ตำแหน่งปลาในช่วงเวลาสั้น ๆ

ปุ่มลัด
------
F6  เริ่มวงจรตกปลาอัตโนมัติ (กดครั้งเดียว)
F7  หยุดฉุกเฉินและส่งเมาส์ขึ้นทันที
F8  เปิดแผงควบคุมและหยุดบอท

ค่าเริ่มต้น
-----------
- Charge target: 94%
- Minigame finish: 98.5%; หาก UI หายหลัง Progress อย่างน้อย 78% จะตรวจยืนยันการจบด้วยเวลา 0.55 วินาที
- การตกปลาใหม่อัตโนมัติ: เปิดตลอด ไม่ต้องกด F6 ซ้ำ
- Recovery: เปิดเป็นค่าเริ่มต้น; พักแบบเพิ่มทีละขั้น สูงสุด 15 วินาทีแล้วตรวจใหม่ ไม่จำกัดจำนวนครั้ง
- Focus Recovery: เปิดเป็นค่าเริ่มต้น; รอให้ผู้ใช้คืน Roblox มาหน้าสุด แล้วสแกนหามินิเกมเดิมก่อนเหวี่ยงใหม่
- เวลาทำงานรวม: 0 = ไม่จำกัด
- Timed Charge fallback: ปิดไว้โดยค่าเริ่มต้น

ข้อจำกัดและความปลอดภัย
----------------------
- Roblox ต้องเปิดอยู่บนหน้าจอและเป็นหน้าต่างที่อยู่หน้าสุด ห้ามย่อเกมหรือสลับไปโปรแกรมอื่นระหว่างทำงาน
- F8 ใช้เปิดแผงควบคุมและหยุดบอท ไม่ได้ย่อ Roblox และไม่ใช่การควบคุมเกมเบื้องหลัง
- ถ้า Roblox เสียโฟกัสหรือหน้าต่างถูกย่อ บอทจะปล่อยเมาส์และพักรอ ไม่คลิกโปรแกรมอื่น; เมื่อกลับเข้าเกมจะสแกน UI เดิมก่อนทำต่อ
- ระบบตรวจจับภาพเป็น computer vision แบบ heuristic อาจต้องเลือกกรอบ B/C/D ให้พอดีกับความละเอียดและ UI ของเครื่อง
- ทดสอบการอ่านภาพกับ Screenshot ที่แนบแล้ว แต่ยังต้องทดสอบ input จริงกับ Roblox บนเครื่องผู้ใช้

แก้ปัญหา
--------
- Charge ไม่พบ: เลือกกรอบ B ใหม่ โดยให้ครอบส่วนเขียว/เหลืองด้านบนและส่วนขาวด้านล่างครบทั้งแถบ
- Charge ไม่เพิ่ม: บันทึก Debug Snapshot; อย่าเปิด timed fallback หากยังไม่ทราบสาเหตุ
- บล็อก/ตำแหน่งปลาไม่พบ: เลือกกรอบ C ให้ครอบรางและแท่งม่วง/เทาให้ครบ แต่อย่ากว้างไปจนติด UI อื่น
- Progress ไม่พบ: เลือกกรอบ D ให้ครอบแถบด้านล่างพอดี
- บอทพักเมื่อสลับหน้าต่าง: ให้คลิกกลับเข้า Roblox แล้วระบบจะทำต่อเอง; ไม่จำเป็นต้องกด F6 ใหม่
- ส่ง logs/fishing_auto_v5_3.log พร้อมไฟล์ PNG/JSON ใน debug/ เพื่อวิเคราะห์เพิ่มเติม

ระบบ Recovery V5.3
------------------
- ข้อผิดพลาดชั่วคราว เช่น อ่านแถบ Charge ไม่พบ, ตัวบอกปลาหายชั่วคราว, มินิเกมหายก่อนยืนยัน หรือรอปลาเกินเวลา: ปล่อยเมาส์ พัก แล้วตรวจ UI ใหม่
- หลังข้อผิดพลาดจากมินิเกม จะสแกนหามินิเกมเดิมนานสูงสุด 8 วินาทีก่อน หากยังเปิดอยู่จะลองกลับไปเล่นต่อ; ถ้าไม่พบจึงเริ่มรอบใหม่
- เวลาพักเพิ่มแบบ exponential back-off และจำกัดเพดาน เพื่อไม่ให้คลิกถี่เมื่อ UI อ่านไม่ได้ซ้ำ ๆ
- การสลับหน้าต่าง/ย่อเกม: หยุด input และรอให้ Roblox อยู่หน้าสุดอีกครั้ง โดยไม่บังคับแย่งโฟกัสจากโปรแกรมอื่น
- ข้อผิดพลาดการตั้งค่าพื้นที่ที่ยังไม่ได้กำหนดหรือหน้าต่างเกมถูกปิดจะไม่วนคลิกซ้ำ เพราะต้องให้ผู้ใช้แก้ไขก่อน
- F7 หรือปิดโปรแกรมเป็นการหยุดโดยเจตนาและจะไม่ถูก Recovery เริ่มกลับขึ้นมาเอง
